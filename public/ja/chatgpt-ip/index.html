よくある質問

ChatGPT や Claude から何が見えているか、どうやって分かるのですか？

chatgpt.com、openai.com、claude.ai、anthropic.com などの AI サイトは Cloudflare の背後にあり、自分のドメインで /cdn-cgi/trace に応答します。接続してきた IP と、Cloudflare が判定した国が返ります。ブラウザはルールが選んだ経路でそれぞれに問い合わせます。

提供対象外の地域は？

OpenAI も Anthropic も、中国本土、香港、マカオ、ロシア、ベラルーシ、イラン、北朝鮮、シリア、キューバではサービスを提供していません。AI サイトからこれらの地域に見えていると、登録や利用が制限されることがあります。

ChatGPT だけ別の IP に見えるのはなぜ？

プロキシのルールで AI 関連のドメインを専用ノードに振り分けていることが多いためです。このページでは AI サービスごとの出口をほかのサイトと並べて表示するので、ルールが意図どおり働いているか確認できます。

データセンターの IP だと問題がありますか？

クラウドやホスティングの IP は多くの人に共有されており、認証や制限を受けやすくなります。家庭用回線やモバイル回線の出口は、そうした扱いを受けにくい傾向があります。

サイトによって見える IP が違うのはなぜ？

Clash、Surge、Shadowrocket、sing-box などのルール付きプロキシや VPN は宛先ごとに経路を選びます。中国のサイトは直接、AI サービスはあるサーバー、それ以外は別のサーバー、という具合です。1 つのサイトに聞くだけでは、そのサイトの経路しか分かりません。このページは数十の宛先に同時に問い合わせ、結果をネットワークごとにまとめます。

WebRTC 漏れとは？

WebRTC（ブラウザのビデオ通話）は UDP で STUN サーバーに自分のグローバルアドレスを尋ねます。TCP しか転送しないプロキシが多いため、この UDP 通信は自分の回線から出てしまい、その結果はどのページも許可なしに読み取れます。STUN サーバーにはローカルのアドレス、サイトにはプロキシが見えている場合、漏れとして表示します。

IPv6 漏れとは？

プロキシが IPv4 しか扱わず、回線に IPv6 もある場合、IPv6 の接続はプロキシを通らないことがあります。IPv6 専用のプローブで、IPv6 の通信が実際にどの出口から出ているかが分かります。

ローカルとプロキシはどう見分ける？

ネットワークの持ち主で判断します。クラウドやホスティング事業者（Amazon、Google Cloud、Alibaba、DigitalOcean など）のアドレスはプロキシ、最初の ISP のアドレスがあなたの回線です。住宅用プロキシや ISP 網上の VPN はこの方法では区別できません。

このサイトに何か送られますか？

いいえ。ブラウザが各プローブに直接接続します。このサイトは静的ファイルを配信するだけで、結果は届きません。スクリーンショットの前に「IP を隠す」を押してください。
